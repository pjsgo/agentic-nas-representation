# Agentic NAS: Architecture Reconstruction

신경망 아키텍처 53개에서 핵심 계산을 골라 YAML로 기술하고 코드로 복원했습니다. 각 구현에 같은 입력과 가중치를 주었을 때 독립 참조와 같은 결과를 내는지 확인했습니다. 예를 들어 LSTM은 길이가 1, 3, 5인 입력에서 출력뿐 아니라 다음 시점으로 넘기는 두 상태도 참조와 일치했습니다.

검증 범위는 각 아키텍처에서 선택한 계산입니다. 전체 모델의 학습 성능은 별도 검증 대상입니다.
