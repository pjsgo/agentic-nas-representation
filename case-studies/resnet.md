# ResNet: 검증 범위와 결과

| 항목 | 기록된 범위와 결과 |
|---|---|
| 검증 범위 | 입력을 그대로 더하는 지름길 연결을 가진 BasicBlock, 채널 수 64, CPU float32 평가 모드 |
| 수치 검증 | 기준 모델 입력 7/7개 통과, 최대 절대 오차 0 |

## 문제와 설계 판단

블록을 대략적으로 설명하면 활성화 함수의 위치, 객체 공유, 텐서 변경 대상이 모호할 수 있습니다. 원본에 근거한 표현에서는 Conv·BN 순서, 입력을 그대로 전달하는 지름길 연결, 공유 ReLU 객체, 제자리 덧셈의 변경 대상을 명시했습니다.

## 확인한 근거

기준 실험에서는 Parameter 6개와 Buffer 6개를 역할별로 대응시켰습니다. 같은 ReLU 객체를 사용하는지와 실제 데이터 흐름을 확인하고, 고정 입력 7개를 비교했습니다. 평가한 생성 코드는 수정하지 않았습니다.

편집 실험에서는 잔차를 더한 뒤 별도 GELU를 사용하고, 독립적으로 만든 편집 기준 구현과 비교했습니다. 입력 8개 모두 해당 기준 구현과 일치했습니다. 마지막 활성화 이전의 계산 경로는 유지됐고, 모든 최종 출력은 원래 모델과 비교 허용오차를 넘는 차이를 보였습니다.

## 이 사례에서 얻은 점

편집 검증에서는 바뀌어야 할 동작과 유지해야 할 동작을 함께 확인해야 합니다. 이 사례는 사람이 지정한 편집 하나의 근거이며, 에이전트의 자율 아키텍처 탐색 능력을 검증한 것은 아닙니다.

## 검증하지 않은 범위

전체 ResNet, 차원을 변환하는 지름길 연결, 학습·기울기, 자율 아키텍처 탐색, 일반적인 생성 성공률은 검증하지 않았다.
