# Mamba: 검증 범위와 결과

**현재 판정: 판정 유보 (INCONCLUSIVE) · 후보 생성: 생성 완료 (COMPLETED)**

| 항목 | 기록된 범위와 결과 |
|---|---|
| 검증 범위 | Mamba-1 selective-scan 핵심부, 검증 조건 4개·비교 텐서 32개 |
| 수치 검증 | 진단용 수치 평가에서 최대 절대·상대 오차 0 |
| 판정 해석 | Parameter 객체 동일성 검사는 통과했지만, 사전 고정한 구조 특징 비교는 실패했다. softplus 기본 인자의 명시 여부와 미리 할당한 출력 버퍼에 복사하는 구현을 동등하게 취급할지는 미해결이다. |

## 문제와 관찰한 불일치

생성된 selective scan은 진단용 수치 평가에서 4개 조건의 비교 텐서 32개 모두 기준과 일치했습니다. 하지만 기존 구조 특징 비교는 실패했습니다.

기록된 차이는 softplus 기본 인자를 명시한 부분과, 출력들을 stack으로 쌓는 대신 미리 할당한 저장공간에 시간별로 복사하는 부분입니다. 현재 기록에서는 이 차이를 허용하는 새 검증 규칙을 채택하지 않았습니다. Parameter 동일성과 수치 검사가 통과했다고 미해결 구조 요건까지 만족했다고 볼 수는 없습니다.

## 이 사례에서 얻은 점

구현의 동등성을 판단할 때는 기본 인자, 인덱스, 읽기 전 쓰기 완료 여부, 외부 텐서 변경을 고려해야 합니다. 몇 개 입력에서 값이 맞는다는 이유로 허용하기보다, 누락된 쓰기나 잘못된 상태 갱신을 검출할 수 있어야 합니다.

## 검증하지 않은 범위

전체 Mamba 블록·모델, Mamba-2, 캐시를 이어 사용하는 실행, 학습·기울기, 다른 자료형·장치는 검증하지 않았다.
