# 실험 자료의 출처와 구성

`experiments/`는 기존 연구 작업 공간에서 선택한 실험 산출물입니다. 공개본의 파일별 대응과 SHA256은 [manifest](../experiments/manifest.json)에 기록했습니다. 원본 실험 파일은 변경하지 않았습니다.

- YAML과 생성된 Python 코드는 원본 바이트를 보존했습니다. 생성 코드는 LLM 출력이며 수작업 구현 성과와 구분합니다.
- `generation-input.json`에는 저장된 요청에서 모델 설정과 메시지만 추출했습니다. 전송 주소·인증·API 클라이언트는 포함하지 않습니다. S4의 입력은 준비된 요청이며 생성 실행을 뜻하지 않습니다.
- JSON·Markdown 보고서의 로컬 절대 경로는 표시용 자리표시자로 바꿨습니다. 전송 주소도 제거하고 문서 링크를 배포 경로로 연결했습니다. 포함하지 않은 참조 파일은 원본 경로로 표시합니다. 해당 변환과 원본 해시를 manifest에 남겼습니다. 보고서 안의 과거 파일 경로는 공개 레포에서 실행되는 경로가 아닙니다.
- 검증 코드는 연구자가 구성한 평가 도구입니다. ResNet 이외의 검증기는 원본 작업 공간의 모듈·fixture·고정 정책에 의존하며, 현재 배포본에서 단독 실행을 지원하지 않습니다.
- 외부 참조 구현의 소스 사본은 포함하지 않았습니다. ResNet 실행 예제는 설치된 `torchvision.models.resnet.BasicBlock`을 사용합니다. 다른 사례의 참조 범위는 각 `source_mapping.md`에서 확인합니다.

PyTorch와 Torchvision은 각 프로젝트의 라이선스를 따릅니다. 본 레포 전체에 대한 재사용 라이선스는 아직 지정하지 않았습니다. 이 자료의 공개가 외부 프로젝트의 저작권이나 라이선스를 대체하지 않습니다.

`recorded/`는 당시 결과이며, `results/reproduction/`은 공개 예제를 별도로 실행해 확인한 기록입니다. 모든 계열을 새로 재실행하거나 새로운 후보를 생성한 것으로 해석하지 않습니다.
