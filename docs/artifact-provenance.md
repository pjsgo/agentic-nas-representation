# 자료 출처

아키텍처별 YAML·최종 구현·논문 및 공식 코드 근거를 제공합니다. `provenance.json`은 코드 출처·생성 모델 설정·확인 범위·생성 후 수정 여부를 기록합니다. 원본 실패와 수정본 성공을 구분하며, 연구 기록 경로는 공개 저장소의 파일 경로가 아닙니다.

관계의 부품 ID가 다른 표현을 요구하면 해당 아키텍처의 `genealogy/`에 표현과 사용 계약을 둡니다. 기본 복원 YAML과 자동 호환된다는 뜻은 아닙니다.

원본 프롬프트·API 응답·실험 로그·상세 평가 보고서는 연구 작업 공간에서 관리합니다. [자료 목록](../experiments/manifest.json)의 기존 해시는 역사적 기록이며 실행 조건이 아닙니다.
