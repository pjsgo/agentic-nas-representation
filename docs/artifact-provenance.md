# 자료 출처

아키텍처별 YAML·최종 구현·논문 및 공식 코드 근거를 제공합니다. 생성 코드와 생성 후 수정 코드는 `candidate_origin`으로 구분하며, 신규 자료의 `provenance.json`에는 기존 검증의 범위와 원본/수정본 판정을 요약합니다. 상세 평가 보고서·API 응답·실행 로그는 연구 작업 공간에서 관리합니다.

관계의 부품 ID가 다른 표현을 요구하면 아키텍처 아래 `genealogy/`에 해당 표현과 출처를 둡니다. 기본 복원 YAML과 자동 호환된다는 뜻은 아닙니다. 관계 파일은 `relations/`에서 한 번만 관리합니다.

[자료 목록](../experiments/manifest.json)의 기존 해시는 과거 기록이며 실행 조건이 아닙니다. 새 배포에서 과거 해시를 재생성하지 않습니다.
