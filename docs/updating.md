# 자료 업데이트

아키텍처별 복원 YAML·최종 구현·사용 계약·출처와 관계 YAML을 함께 관리합니다. 두 저장소는 같은 계산과 근거를 제공하며, 개인 저장소의 `experiments/`와 공유 저장소의 `architectures/`에 맞춰 상대 경로만 조정합니다.

아키텍처 자료를 변경하면 목록과 `provenance.json`을 함께 갱신하고, 관계가 참조하는 YAML 경로와 부품 ID를 확인합니다. 생성 모델 설정은 출처 파일 안에서 관리합니다. 생성 원본과 수정본의 판정·범위는 구분합니다.

공개 자료에는 사용과 해석에 필요한 정보만 둡니다. 원본 프롬프트·API 응답·실험 로그·fixture·상세 평가 보고서·과거 구현 사본은 연구 작업 공간에서 관리합니다. README에는 세션 진행 상황이나 작업 계획을 적지 않습니다.
