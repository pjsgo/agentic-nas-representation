# 자료 업데이트

아키텍처 계보에 따라 YAML과 복원 코드를 추가합니다. 기존 실험과 다른 입력·후보는 별도 실험 폴더로 구분합니다.

자료를 추가하면 아키텍처 목록, 자료 manifest와 summary.json을 함께 갱신합니다. README와 공통 안내 문서에는 정의·형식·작성 기준·해석 규칙·사용 방법·일반 예시만 적습니다. 세션 진행 상황, 완료·미완료 여부, 호출·배포 여부, 완료 개수, 작업 날짜, 다음 작업이나 향후 구현 계획은 넣지 않습니다. 복원 YAML과 관계 YAML은 역할을 구분해 각각 설명합니다. 개별 평가 보고서와 실험 이력은 개인 레포에 복사하지 않습니다.
