# 담당 범위

팀 연구 중 구조 분해와 표현 설계, 아키텍처별 YAML 작성, 재구성·검증 절차 구현과 실패 분석을 담당합니다. 아키텍처 계보 분석과 향후 평가용 데이터셋 준비는 각각 다른 연구원이 담당합니다.

[실험 자료](../experiments/README.md)의 생성 후보는 LLM 출력입니다. 제 기여는 표현과 실험 조건을 설계하고, 검증 도구로 결과를 확인·분석하는 작업입니다. 외부 아키텍처와 참조 구현의 저자는 각 원 프로젝트에 있습니다.

현재 결과는 선택된 블록과 핵심 연산에 한정됩니다. 전체 자율 NAS 시스템이나 탐색 성능은 후속 연구 대상입니다.
